## 1. 邮件系统在哪

| 环节 | 位置 |
|---|---|
| 邮件数据表 | `GameDB.dbo.GameEmail`（当前 0 封） |
| 写库/读库 | 存储过程 `PrGs_GameEmail_Add_V5` / `Get_V3` / `Open_V1` / `Update_V5` / `Del_V2` / `Confirm` |

`GameEmail` 表结构：

| 字段 | 类型 | 说明 |
|---|---|---|
| FromActorID | int | 发件人角色 ID。**< 1000 视为系统邮件**（不受 10 秒限频、不受维护拦截） |

| AttachNum | tinyint | 附件格数 |

| GoodsIcodID | int | 第一格附件的物品 ID（由存储过程自动从 GoodsBuf 解析） |

## 2. 怎么发邮件（三条路）

### A. 脚本发（官方做法，推荐）

从全服脚本里反推出来的签名（`MeiLaoBanList.lua`、`SpringFestival.lua`、`CommandFromExarch.lua` 等大量在用）：

```lua
API_SendActorMail(ActorID, GoodsID, GoodsNum, Title, Body)
API_SendActorMailEx(ActorID, GoodsID, GoodsNum, Bind, Title, Body)
API_SendActorMailByName(ActorName, GoodsID, GoodsNum, Bind, Title, Body)  -- 按名字，离线也能收到
API_SendActorMoneyMail(ActorID, Money, Title, Body)          -- 发金币
API_SendActorMoneyMail_UnLine(Name, Money, Title, Body)      -- 离线金币邮件
API_SendActorMoneyMail_UnLineEx(...)                          -- 离线多附件邮件
```

`Bind` = 绑定标记（本端配置注释：1=不绑定，0=绑定；脚本里活动赠送常见 3）。

现成例子（可直接照抄）：

```lua
-- MeiLaoBanList.lua:1326
API_SendActorMailByName(RankPlayName, 82004, 500, 0, '上周排行榜1-10名', '系统奖励您500个...')

-- CommandFromExarch.lua:3778
API_SendActorMoneyMail(lActorID, 金币数, '总督密令报酬[金币]', '...')

-- UseLiBaoItem.lua:264
API_SendActorMailEx(ActorID, 11114, 1, 0, '燃放烟花获得节日招财装', '请查收！')
```

### B. GM 面板（`GM脚本.lua`）

把 `工具及教程\GM脚本.lua` 改好角色 ID，在场景服窗口“浏览 → 更新”刷进去，游戏里就有紫色闪电 GM 面板。
**但面板里没有“群发邮件”功能**，只有：在线查询、加物品、加状态、加神降/魔附、改时间、抽奖等。

### C. 直接写数据库

- 纯文字 / 纯金币邮件可以直接 INSERT（`AttachNum=0, GoodsBuf=NULL`），见 `全服发点券.sql` 第 5 节。
- **带附件的邮件不要手搓 `GoodsBuf`**，写错会变空格子甚至崩服。要么走脚本 API，要么调 `PrGs_GameEmail_Add_V5`。
- 存储过程里的两条硬规则：
  1. 发件人 ID > 1000 时，若 `Aawh` 表 `whzt=1`（维护中）会被拦；
  2. 同一个收件人 **10 秒内只能收一封**（`Actor.EmailTime` 控制），否则返回“邮件限制每10秒允许发送一次!”。

## 3. 可以发什么东西

邮件里能放 = **金币（MoneyNum）** + **最多若干格物品（物品ID + 数量）**。

物品 ID 来源（端内配置 + `工具及教程\魂器端代码大全\*.csv` 反查）：

- 装备：`Scp\Equipment.cse`
- 材料 / 货币：`材料等.csv`，其中 **80082 = 点券**（单格上限 30000）
- 宝石：`Scp\Gem.cse`、`宝石等.csv`
- 药品：`Scp\Medicament.cse`
- 时装：`时装等.csv`
- 礼包 / 宝箱：`礼包等.csv`
- 宠物 / 载具：`载具宠物等.csv`
- 常用兑换券：80498（经验兑换券）、80696（水晶币兑换券）、80289（购物券）

**没法用邮件直接发的**：点券货币字段本身、经验、等级、士气、爵位、阵营 —— 这些只能改库或写脚本。

## 4. 能不能给所有人发点券

**结论：能，但邮件没有“全服群发”按钮，得自己绕。**

点券有两副面孔，注意区分：

1. `GameDB.Actor.Point` —— 角色身上的点券货币（当前全服都是 0，上限 99999999）。
2. 物品 **80082「点券」** —— 可交易的货币道具（交易所里买卖的就是它，单格上限 30000）。

所以“发票”有两个办法：

### 办法一：邮件群发（推荐，在线离线都能收到）

写一段 Lua 遍历角色名，逐个 `API_SendActorMailByName(名字, 80082, 数量, 1, 标题, 正文)`。
离线玩家下次登录邮件就躺在邮箱里。
成品脚本：`GM_MailAll.lua`。
安装三步（本端脚本**不会自动加载**，必须在 `Other_Main.lua` 里 require）：
1. 把 `GM_MailAll.lua` 放进 `Server1\Scp\Lua\Other\`
2. 在 `Server1\Scp\Lua\Other\Other_Main.lua` 末尾加一行：`require 'Scp\\LUA\\Other\\GM_MailAll.lua'`
3. 场景服窗口 → 浏览 选中 `Other_Main.lua` → 更新

想让它出现在 GM 面板上，按 `GM面板加按钮.txt` 往 `GM脚本.lua` 的菜单里插三行链接。

### 办法二：直接改库（最省事，但要先让玩家下线）

```sql
USE GameDB;
UPDATE dbo.Actor SET Point = Point + 1000;   -- 点券上限 99999999
```

⚠️ 关键坑：**必须让角色离线后再改**。在线角色的数据在服务端内存里，`Server1\config.ini` 里 `TimeSave=10`（每 10 秒存盘一次），会把你的修改覆盖掉。这条和教程文档《英雄岛修改点卷，名字等等教程.docx》说的一致。

### 办法三：充值通道

`PayCenter.GameUser_Points`（充值/消耗点数流水），配 `PrGs_GameUser_Points_Add` 走官方充值逻辑，当前表是空的。

### 另外别忘了开 CLR

当前 `clr enabled = 0`。这就是教程《邮箱不能领东西教程.docx》要解决的问题——不开 CLR，邮箱里的东西领不出来。

```sql
USE master;
EXEC sp_configure 'show advanced options', 1; RECONFIGURE;
EXEC sp_configure 'clr enabled', 1;           RECONFIGURE;
```

### 修 PrGs_GameUser_Points_Query 返回 NULL

问题：`PayCenter` 版是 `SELECT @Out_Points = Points FROM GameUser_Points WHERE UserID=@UserID`，表为空 → 输出 NULL；`GameDBArea` 版查 `account.Point`，该列全为 NULL → 同样输出 NULL。服务端把 NULL 输出当成"未知错误"（抛包日志 `请求ID=120`）。

修法：在两条查询前 `SET @Out_Points = 0`，查询后 `SET @Out_Points = ISNULL(@Out_Points,0)`。

原定义已备份到 `备份-原存储过程\{库}.PrGs_GameUser_Points_Query.sql`。
返回值：修前 `NULL` → 修后 `0`，已实测。

注意：这只修了**计费库点券查询（请求 120）**。**角色身上的点券读取是请求 121（`GameDB.PrGs_GameUser_Points_Get`）**，那个还是占位返回 -1，没做。
