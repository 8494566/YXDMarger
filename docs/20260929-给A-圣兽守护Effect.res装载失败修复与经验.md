# 2026-09-29 圣兽守护 / 供奉神祇 —— Effect.res 装载失败修复 + 经验总结（B 给 A）

## 一、这次到底是什么问题（结论）

客户端进不去游戏，弹 `Effect.res 创建失败`。根因在 **`shared/scp/Effect.res`**：

- `Effect.res` 的**真实内容是「脚本」**，不是 CSV：
  ```
  MaxID = 549001
  Object 基本属性和… = 1          <- 顶层对象（带 TypeID）
  {
      TypeID = 1
      Params = 0
      Des = 基本属性和…
      Object 物理攻击：3 = 1001    <- 子对象（无 TypeID）
      { Params = 7,3   Des = 物理攻击：3 }
      …
  }
  Object 逃亡者的决心伤害 = 549      <- 后面这些也是顶层对象（各带 TypeID）
  { TypeID = 101  … }
  ```
- **对象归属哪一组，由它在脚本里的「嵌套位置」决定**（工具转成 csv 时给出的 level 列就是这个）：
  - 顶层对象本身 → `level = -54`
  - 顶层对象的**子对象** → `level = -53`（`-54` 组的子对象）/ `level = 2`（`基本属性和… = 1` 的子对象）等
- **每组有 ID 段限制**（旧表实测）：
  | level | 行数 | ID 范围 |
  |---|---|---|
  | -54 | 274 | 23 ~ 549 |
  | -53 | 3706 | 23001 ~ 549001 |
  | -20 | 88 | 128034 ~ 129033 |
  | 1 | 198 | 1 ~ 374 |
  | 2 | 27855 | 1001 ~ 374020 |
- **原实现把 505 个 Object 直接追加到了脚本「最末尾」**（紧跟 `= 549` 那组后面，属于顶层位置，且没写 `TypeID`）→ 客户端按 `-54` 组解析 → 而该组 ID 只到 549，`30093~30597` **超出范围** → `ERROR: Init filesystem  script load failed[…] scp Effect.res` → **游戏打不开**。
  （`BasicSys.dll` 里就是这个报错模板；同类装载器还有 `ColdTime.dll` 的 `类型%d或者值%d超出范围`。）

## 三、★血泪教训（工具用法）

1. **`.res` 必须走 `res→scp`(模式3) / `scp→res`(模式6)**，这是**字节级无损、完全回环**的路径。
   - **不要**用 `res→csv`(4) / `csv→res`(2)：**有损**——它会补空格，而且会把 `-54` 归一化成 `1`，直接毁掉分组！
   - `.cse` 才用 `cse→csv`(7) / `csv→cse`(0)。
2. 改完必须回环校验：`解密(加密(改后)) == 改后`（`.res` 用 3→6→3 比；`.cse` 用 7→0→7 比）。
3. **`.res` 直接看 csv 会看不到真身**（csv 是工具的「视图」，字段被裁剪、level 是推导出来的）。要看真身、要改，一律走 `.scp`。
4. 往脚本里加新对象时，**必须想清楚它应该嵌套在哪个父对象下面**（决定 level / ID 段），不能甩到文件末尾。
5. 新增对象最好**照抄同类父对象的结构**（顶层对象都要带 `TypeID`；子对象只写 `Params`/`Des`）。

## 四、本次其它坑（顺带记录）

1. **客户端 `.fsp` 资源包不能拿别的服的同名包整体覆盖**——即使文件头格式一致（都是 `PACK`/`BLCK`）、`FileSystem.dll` 一致，里面也可能有本服特有资源，换完客户端可能起不来。要补资源只能**按条目合并**（`D:\YXDTool\PackViewer.exe` / `Packager.exe`）。
2. 判断「某张表有没有被手改」，**必须把同名 `.csv`/`.scp` 中间文件一起看**，只看 `.cse/.res` 会漏（有人只改了 csv 没加密回去）。
3. 装表/改表后**服务端必须重载**：表 → 服务端窗口「浏览+更新」（或重启）；Lua → 「脚本更新」。`.cse/.res` **不能**按「脚本更新」。
4. 本机**机器时钟比会话时间慢约 7 小时**，读文件 mtime 判断"几小时前改的"会误判；以服务端日志时间戳为准。
5. 双端表改完记得同时更新客户端 + 发布站，并重生成 `scp.txt`（`bb` 变化客户端才会拉）。
