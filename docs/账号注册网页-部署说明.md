### 下载站的扩展名（重要，已修）

IIS 的静态文件处理器只发送**已注册 MIME 类型**的扩展名，未注册的会返回 `404.3`（不是普通的文件不存在）。默认 IIS 只认 `.txt` / `.zip` / `.css` / `.js` / `.png` / `.exe` / `.rar` 等常见类型 —— 你把整个 `scp\` 资源包放进去时，`.ini` / `.bat` / `.res` / `.cse` / `.scp` / `.rcf` / `.dat` 全被拒了。

**已加通配兜底**：站点级加了 `*` → `application/octet-stream`，现在**任何扩展名**丢进去都能下载；另外把 `.ini` / `.txt` 映射为 **`text/plain; charset=utf-8`**，浏览器里直接打开中文不会乱码。修完实测目录里 **243 个文件全部 HTTP 200**。

**charset 规则**：文本文件在浏览器里乱码，几乎都是因为响应头只写了 `text/plain` 而没带 `charset`，浏览器只能猜。要让浏览器正常显示，映射里的 charset 必须**跟文件真实编码一致**。当前目录里两种编码都有：

| 文件 | 实际编码 |
| --- | --- |
| `list.ini`、`start.bat` | UTF-8 无 BOM |
| `scp\GameSetting.ini` | UTF-8 带 BOM |
| `scp\Skill.scp`、`scp\lul.scp`、`scp\tlul.scp`、`scp\tsul.scp`、`scp\Medicament.csv`、`scp\Framesort.dat` | GBK/GB2312（ANSI） |
| `scp\scp.txt` | 纯 ASCII |

所以 `.scp` / `.csv` / `.dat` 这些 GBK 数据文件保留了二进制下载（不渲染，就不会乱码）；如果以后要改某个扩展名的 charset，记得先确认文件本身的编码。

**注意**：兜底映射只管“发送文件”，不管“执行文件”。因为装了 ASP.NET，`C:\ShareFiles` **根目录里如果放 `.aspx` / `.ashx`，IIS 会执行它而不是提供下载**。这个下载目录只放数据文件/压缩包就好。

## 三、端口这件事（备案 + 实测结论）

**换端口过程**：80 → 8080 → **35179**（按你的要求换到远离 Web 端口簇的小众口）。

**一条重要的实测结论**：我用 check-host.net 从多个境外节点（巴西/加拿大/以色列/葡萄牙、以及德国/印度/荷兰/土耳其）对 `:8080` 发的是**真实 HTTP 请求**，返回的是我们自己 IIS 的 `404 Not Found`，**不是**腾讯云的备案拦截页。也就是说 8080 在网络上其实是通的，备案拦截没有作用在这一层。

不过既然你那边用 80/8080 都被拦，就按你的判断换到 35179 了 —— 这个端口不属于任何常见 Web 端口簇（不是 80/443/8000-8090/8888/3128 那一片），最不容易被误判。

**换端口命令（以后随时可换）**：

```powershell
$old = 35179; $new = 45000   # 改成你要的端口

Remove-WebBinding -Name 'Default Web Site' -BindingInformation ("*:{0}:" -f $old)
New-WebBinding    -Name 'Default Web Site' -Protocol http -Port $new -IPAddress '*'
New-NetFirewallRule -DisplayName ("GameWeb HTTP {0}" -f $new) -Direction Inbound -Protocol TCP -LocalPort $new -Action Allow -Profile Any
Remove-NetFirewallRule -DisplayName ("GameWeb HTTP {0}" -f $old)
```

> 注册页内部所有链接（表单 action、验证码、reg.js）都是**相对路径**，换端口不用改任何代码。

**选端口建议**：避开 1024 以下、避开 49152 以上（Windows 客户端临时端口段），也别用 1433（SQL Server）、47001/5985（WinRM）、3389（远程桌面）。

## 五、完整可照抄的 INSERT 语句

注册页实际执行的就是这一条（三个值全部参数化）：

```sql
INSERT INTO dbo.account (UserName, PassWord, SecPsw)
SELECT @UserName, @PassWord, @SecPsw
WHERE NOT EXISTS (SELECT 1 FROM dbo.account WHERE UserName = @UserName);
```

C# 侧（外层 `SERIALIZABLE` 事务，靠键范围锁防并发重复注册，所以数据库账号**不需要 UPDATE 权限**）：

```csharp
using (SqlTransaction tx = cn.BeginTransaction(IsolationLevel.Serializable))
{
    using (SqlCommand cmd = new SqlCommand(SQL_INSERT, cn, tx))
    {
        cmd.Parameters.Add("@u", SqlDbType.VarChar, 32).Value = user;      // UserName
        cmd.Parameters.Add("@p", SqlDbType.VarChar, 40).Value = sha1hex;   // PassWord
        // SecPsw 传同一个值
        int n = cmd.ExecuteNonQuery();
        if (n == 1) { tx.Commit(); }   // 注册成功
        else { tx.Rollback(); }        // 账号已存在
    }
}
```

**手动加号（GM 用，SSMS 里直接跑）：**

```sql
DECLARE @u varchar(32) = 'test001';
DECLARE @p varchar(20) = 'Test123456';
DECLARE @h varchar(40) = LOWER(CONVERT(varchar(40), HASHBYTES('SHA1', @p), 2));

IF NOT EXISTS (SELECT 1 FROM GameDBArea.dbo.account WHERE UserName = @u)
    INSERT INTO GameDBArea.dbo.account (UserName, PassWord, SecPsw) VALUES (@u, @h, @h);
ELSE
    PRINT '账号已存在';
```

> SQL 2012 的 `HASHBYTES` 对 `varchar` 输入按字节算，和登录端一致；`CONVERT(...,2)` 是大写，所以套了 `LOWER()`。

## 七、查重逻辑

两层，缺一不可：

1. **原子层（真正防重）**：`INSERT ... SELECT ... WHERE NOT EXISTS(...)` 外套 `SERIALIZABLE` 事务。并发注册同一账号时，`UserName` 索引 `user_name` 的键范围锁让第二个请求阻塞，最终只有一个成功，`@@ROWCOUNT=0` 的那个返回「账号已被注册」。直接跑 SQL 也不会重复。
2. **交互层**：注册页把 `ExecuteNonQuery()` 返回 0 映射为提示「账号已被注册，请换一个。」

> `UserName` 索引是非唯一索引，靠它本身挡不住重复。想更省事可以给 `UserName` 建唯一索引（先确认现有数据没重复）。

## 八、安全措施（逐条对应要求）

| 要求 | 实际做法 |
| --- | --- |
| 参数化查询，禁止拼接 SQL | 全部 `SqlParameter`（`@u` / `@p`），SQL 文本是常量。账号含引号在正则层就被拒，绕过也只会当参数值 |
| 服务端白名单校验 | 账号 `^[A-Za-z0-9]{4,16}$`；密码 `^[\x21-\x7E]{6,20}$`（可见 ASCII、不含空格）。前端 `maxlength` 只是体验 |
| 密码长度 + 两次一致 | 服务端强制 6–20 位；不一致直接拒绝 |
| 防刷 | 同 IP 每分钟最多 5 次（超出提示「提交过于频繁」）+ 图形验证码 |
| 图形验证码 | `captcha.ashx` 用 GDI+ 生成 PNG（旋转 + 干扰线 + 噪点），存 Session，**任何 POST 先删除再比对**，不可重放 |
| 不用 sa 跑网站 | 数据库登录名 = 应用池标识 `IIS APPPOOL\RegApp`，权限**只有** `CONNECT` + `SELECT` + `INSERT ON dbo.account`，无其他表、无服务器角色 |
| 数据库密码不进客户端 | 没有数据库密码 —— Windows 集成认证，`web.config` 只有 `Integrated Security=SSPI` |
| 其他 | `web.config` 被 IIS 拦（实测 404）；关闭 `X-Powered-By`；`X-Content-Type-Options` / `X-Frame-Options`；远端只显示通用错误；Session 10 分钟超时 |
