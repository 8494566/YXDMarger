## 2. 结论：客户端那份方案的改法（4 处）

| 原方案 | 改成 |
|---|---|
| `robocopy /MIR` 到站点 | ⚠️ **绝对不能用 `/MIR`** —— 会把 `C:\ShareFiles\scp`、`res` 里那些 git 里没有的客户端包和图片**删光**。改用 **`/E`**（只增改、不删） |
| `app_offline.htm` + 回收应用池 | **删掉**。那是 IIS 网站的做法；我们这里是**游戏服 + 发布站**，游戏服不认这套 |
| GitHub 当"唯一真源" | ✅ 保留（**测试环境直接建公开仓库**最省事：计划任务免密钥、免交互），私有仓库也行（Deploy Key 只读） |
| 只部署一个 IIS 站点 | 实际是 **3 个同步目标**：<br>① 发布站 `C:\ShareFiles`<br>② 游戏服 `D:\Server\server\Server1`（表 + Lua）<br>③ 客户端工程 `D:\六星魂器…\英雄岛一键端`（`Data\Scp`、`Data\Res`） |

**另外两件事**：
- **路径去中文**：建两个 ASCII 软链接，脚本全部用 ASCII 路径（不移动数据）：
  ```
  D:\YXDClient  ->  D:\六星魂器英雄岛加修复交易所数据库\英雄岛一键端\英雄岛
  D:\YXDServer  ->  D:\Server
  ```
  之后统一写 `D:\YXDClient\Data\Scp`、`D:\YXDServer\server\Server1\Scp`。
- **改了文件 ≠ 生效**：Lua 要在服务端点「**脚本更新**」；表要「**浏览+更新**」；或者重启 `D:\YXDServer\[2]一键启动.bat`。

## 4. 远程改数据库（怎么方便怎么来）

- **最省事（推荐）**：远程桌面连进来，在服务器本机用 **SSMS** 改库 —— 不用开任何端口，也不会有连不上/超时的问题。
- **想在自己电脑上连**：SSMS / Navicat / HeidiSQL 连 `42.193.197.163,1433` —— 需要：
  1. 服务器放行入站 1433（我可以帮你加这条防火墙规则）；
  2. SQL Server 已启用 TCP（现在 1433 就是监听状态 ✓）；
  3. 一个能登录的账号（建议建个 `yx_mod` 专用账号；账号密码你自己在 SSMS 里设，我不经手）。
- **建议保留的一件"安全"事**：**每天自动备份**。测试环境删错表/改错数据一样要命，而 SQL Express 没有自带作业，`db_backup.ps1` 就是干这个的。

### 5.3 编辑铁律（踩过的坑，别再踩）

1. `.cse/.res` **只能用官方工具**：`D:\YXDTool\脚本转换工具\Encrypt.exe`（右键解密 → 改 → 右键还原）。**不要自己写脚本 XOR**。
2. 命令行模式：`csv=>cse=0`、`csv=>scp=1`、`csv=>res=2`、`res=>scp=3`、`res=>csv=4`、`scp=>csv=5`、`scp=>res=6`、`cse=>csv=7`。
3. **产物名与输入同名**：`xxx.csv` → `xxx.cse`。
4. 改 `.cse/.res` 解出的 CSV：**绝不能用 `splitlines()` 重排整份**（`\x0b/\x0c/\x85` 会被当换行 → 文件废掉）。用**纯字节精确替换** + **回环校验**。
5. 表里**不能有重复 ID**；特别注意**不能出现双回车 `\r\r`** → 会生成空记录 → 报「怪物ID: 0 配置重复」→ **整张表装载失败**（踩过）。
6. 新建/改写服务端 Lua **必须 GBK**（UTF-8 会乱码/白屏）。
7. 批量改同一张表：**每次基于当前线上文件重新解密**，别复用上次的解密结果（会覆盖前面的改动）。
8. 改完 Lua 做括号平衡自检；改完表做回环校验 + 字段数/重复 ID 检查。
9. Python 别用 `-c` 内联中文/引号（必炸）→ 写成 `.py` 文件再跑。
10. PowerShell 脚本**别存成"UTF-8 无 BOM"**（PS 5.1 按 ANSI 读 → 语法错）→ 纯 ASCII，或 **UTF-8 带 BOM**。
11. 客户端对话框内容**别太长**（约 4.7KB 以上就渲染不出来）→ 长列表要分页。
12. `<a href>` 必须写在 `<text>` **外面**才渲染成按钮；对话框里 ASCII 方括号 `[...]` 是特殊标记，要改全角。
13. 生效方式不同：**Lua → 「脚本更新」；表 → 「浏览+更新」或重启**。
